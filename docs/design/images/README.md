# Designbilder

Skisser och skärmbilder för [`../ui-ux.md`](../ui-ux.md). Ägaren tar fram bilderna.

- **Namn:** `NN-skärm-tillstånd.png`, till exempel `02-session-list.png`. Numret och namnet ska
  matcha tabellen i avsnitt 7 i `ui-ux.md`.
- **Format:** PNG eller JPG i stående läge. SVG går också bra för wireframes. Använd helst
  storleken på en Galaxy S20-skärm eller en skiss i samma proportioner.
- **Innehåll:** Använd påhittade exempelvärden. Lägg inte in riktiga foton av måltavlor,
  personuppgifter eller annat privat material.
- **Ändringar:** Om en bild ersätts ska det nya utseendet stämma med texten i `ui-ux.md`,
  eller så uppdateras dokumentet i samma ändring.
