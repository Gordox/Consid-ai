TARGET PRACTICE / DESIGN SYSTEM 2.0

Clarity at every round.

A precise, calm interface for photos, reviewed hits and a lasting practice log. Orange means action. Every score tells you what it is based on.

ComponentsAndroid screensiPhone screensScreen navigator
Design reference, not a working scoring app. All targets and scores are illustrative demo data. Native camera, permissions, gestures and accessibility require device verification.
